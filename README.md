Tienda online de productos electrónicos de salud y bienestar con estética viral, pensada para vender por redes sociales (TikTok / Instagram).

🌐 **Ver la tienda en vivo:** https://uknowgt1.github.io/tienda/

## ✨ Qué incluye

- Catálogo de productos con filtros por categoría
- Carrito de compras con cálculo de total
- Checkout con datos de despacho
- Resumen de pedido listo para copiar y montar manualmente en Dropi
- Pago con tarjeta vía Webpay (Transbank) Link de Pago — *en proceso de contratación*

## 🛠️ Cómo está hecha

Es un único archivo HTML autocontenido (`index.html`): HTML + CSS + JavaScript e imágenes incrustadas, sin dependencias ni proceso de compilación. Se publica tal cual con GitHub Pages.

## 📁 Archivos

| Archivo | Descripción |
|---|---|
| `index.html` | Todo el sitio (página única autocontenida) |
| `banner.png` | Imagen de portada usada en este README |
| `README.md` | Este archivo |

## 🚀 Publicación

El sitio se publica automáticamente con GitHub Pages desde la rama `main`. Para actualizar la tienda, reemplaza `index.html` y el cambio se refleja en minutos en https://uknowgt1.github.io/tienda/
